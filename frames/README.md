# 📁 frames/ — YAHAN APNI IMAGES DAALO

## Kaise daalna hai (GitHub se — 100% chalega)

1. Browser me kholo → **github.com/abhishekkumar009988/driver-safety**
2. **`frames`** folder par click karo
3. Upar right me **"Add file"** → **"Upload files"** dabao
4. **Saari images drag & drop** kar do (PDF bhi chalega — main khud nikal lunga)
5. Neeche **"Commit changes"** dabao
6. Mujhe yahan bol do → **"upload ho gaya"**

Bas. Main `git pull` karunga aur saari 29 frames dekhlunga.

## Upload ke baad main kya karunga

1. Har frame ko dekhunga — **5-5 karke group me** (jaisa aapne bola)
2. Har frame ka audit:
   - character identity — chehra same hai ya badal raha
   - face acting — aankh, honth, bhaav kaise badalte hain
   - eye-line — kaun kise dekh raha hai
   - haath kya kar rahe hain, kya hold kiya hai
   - kapda/odhni kis state me hai
   - gehna kis position me hai
   - body weight, posture
   - shot distance, camera angle
   - background — kya peeche hai
   - location — agle frame se kaise juda hai
   - transition type — kaise merge ho raha hai
   - emotional progression — feeling kahan se kahan gayi
   - natural VFX — hawa, phool, dhuan, roshni
   - **2 stories ka connection point**
3. Phir **`AI-FILM-PROMPTS.md` me hi correction** karunga — naya prompt nahi banaunga
4. Jo bhi naya pattern milega, wo usi file ke andar chala jayega
